# Adaptive RAG Web 前端

基于 React、TypeScript 和 Vite 的聊天工作台。界面采用 ChatGPT 式布局，支持流式回答、来源引用、本地会话搜索与人工确认卡片。

流式接口只在答案完成校验后发送可展示的文本，不向用户展示模型生成的内部 JSON、检索策略或耗时信息。进度分为“图外准备”和“图内工作流”：前者实时显示限流检查、原始输入护栏、会话归属与确认凭证校验、恢复记忆、上下文解析、初始化状态，区分进行中、已完成和失败；后者显示实际完成的 LangGraph 节点。准备阶段不计入节点数量，图仍为 9 个业务节点。结束后进度折叠，可展开查看；中止或失败时停止加载动画。进度会随回答保存，刷新或从服务端恢复历史后仍可查看。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，以及 npm。

先在仓库根目录启动 FastAPI（默认开发端口 8002），再开一个终端：

```bash
cd frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 默认将 `/api` 代理到 `http://127.0.0.1:8002`，也可通过 `VITE_API_BASE` 指定 API 地址。

后端在 `APP_ENV=development` 时默认每次启动恢复 `u_demo` 的三条演示订单及其明细、相对时间，并清理关联的退款、退货、操作日志和幂等结果。输入“取消订单 ORD10003”即可体验确认卡片；点击“确认执行”后，订单从 `paid` 变为 `cancelled`，仍然保留在数据库中。重启后端后恢复为 `paid`，即可再次演示。可设置 `RESET_DEMO_ON_STARTUP=false` 保留操作后的状态，或设置 `SEED_DEMO_ON_STARTUP=false` 关闭整个自动初始化。浏览器历史消息保留，下一轮演示可新建对话。

## 构建与检查

```bash
npm test
npm run build
```

构建结果在 `frontend/dist`。FastAPI 检测到该目录后会在 `/` 提供页面；Docker 镜像会在 Node 构建阶段自动生成并复制它。

## 数据与身份边界

- 浏览器按用户分别缓存会话，最多保留 50 个会话、每个 100 条消息。打开页面从服务端同步会话列表，选中时恢复消息、引用和有效确认卡片；同一用户清除缓存或换浏览器后也可从同一后端恢复。消息更多时可通过历史 API 分页读取。
- 后端返回的 `session_id` 会随会话保存，继续对话时复用。
- 会话原文、滚动摘要和当前订单/未完成诉求保存在数据库；新对话使用独立记忆。支持“我要退掉马克杯 → ORD10002 → 点击确认”的连续操作。完整说明见[会话记忆](../docs/21-conversation-memory.md)。
- 待确认操作保存在数据库中，有效期 15 分钟；重启或切换进程不会丢失。开发模式恢复演示订单时会作废关联旧卡片；过期、取消或被新提案替代后也不能执行。
- 右上角橡皮擦按钮可清空当前会话记忆，保留可见历史；后续请求不再读取清空前的消息。删除会话会同步删除服务端聊天记录、摘要及待确认操作，已执行的业务数据仍然保留。
- `VITE_DEMO_USER_ID` 默认为 `u_demo`，仅用于本地演示。后端**尚不认证**请求中的 `user_id`。面向不可信用户部署前，必须由可信认证层在服务端绑定身份。
- `VITE_API_BASE` 可指向独立部署的 API；此时该 API 需要明确允许前端来源。
